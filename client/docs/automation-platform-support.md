# Browser Use / Computer Use 平台与安全边界

首页按后端实时检测展示能力。Browser Use 需要安装 Chrome、Edge 或 Chromium；Computer Use 还取决于系统截屏与输入权限。Linux 自动化底层可用不代表已有 Linux 桌面安装包。

| 平台 | Browser Use | Computer Use 条件 |
| --- | --- | --- |
| macOS Intel / Apple Silicon | macOS 14 及以上使用内置 WebKit，其他版本可使用受控 Chromium | EchoAgent 获得「屏幕录制」和「辅助功能」权限 |
| Windows | 使用内置 WebView2，可显式连接浏览器扩展 | 桌面截图与输入能力检测通过 |
| Linux X11 | 检测到 Chromium 系浏览器后可用 | X11 会话提供 XTEST 扩展 |
| Linux Wayland | 检测到 Chromium 系浏览器后可用 | 不启用全局截屏和输入注入；需切换 X11 会话 |

macOS AX / Windows UI Automation 控件层复用同一 Computer Use 入口、Runtime 和审批。接口与读取限制见 [原生桌面控件](desktop-control/README.md)，实机判定方法见 [桌面控制验收](desktop-control/validation.md)。支持能力与特定版本的验收结果分别记录。

## 任务控制与确认

- 每个任务有独立标签和下载目录。内置浏览器的公网登录和最近访问地址按账号保存。删除任务清理该任务的数据，自动化任务在应用重启后以暂停状态恢复。
- 活跃和已归档的会话保留到用户明确删除为止。升级后，旧配置 `[storage] cleanup_ttl_days` 的值不再用于自动清理历史。中断的会话搬迁在后台恢复，打开受影响会话时会等待该会话的恢复。
- 浏览器副作用仍由后端单独确认。电脑任务由用户的明确请求启动，任务内键鼠、启动/激活应用及原生控件连续执行，不逐步确认，不按应用名称或按钮关键词弹窗。普通 Runtime 权限不能自行制造任务执行授权；暂停、停止、切换模式和重启撤销旧令牌。
- 暂停会取消在途和待执行操作，并等待实体输入退出；原生对象身份、窗口焦点、保护字段及截图帧校验保留。用户在同一聊天发送“停一下”或“继续保存”等明确指令即可暂停或续做；暂停时的“继续任务”快捷入口走同一次消息发送，生成间隙保留暂停入口，不需要双重恢复。加载历史不会恢复执行。
- 明确电脑请求自动接入真实 Computer Use 工具配置；旧的工具菜单仍可用于手动选择能力。缺少系统权限时显示一次系统设置引导；需要原请求未包含的关键选择时，任务层提出具体问题。浏览器密码字段不会进入 DOM 快照，也不接受工具输入。
- 原生控件识别使用系统对象身份；应用本地化名称只是显示信息。操作未知时先观察，不盲目重放保存或发送。权限拒绝仍保留原有约束。
- 日期、时间和数字控件使用完整规范值（例如日期 `YYYY-MM-DD`、时间 `HH:mm`）替换填写，并回读实际值与页面校验状态；下拉选项不存在或不唯一时返回错误。字段填写成功仍需继续提交，并核对保存结果。
- 富文本框的填写验证保留实际行结构，支持连续空行、末尾换行与清空；浏览器用于放置光标的占位换行不计入正文。
- 网页内容、浏览器截图和电脑截图会作为任务上下文发给当前选用的模型服务。

## 网页面板

普通聊天外链使用系统浏览器。需要同屏查看时，点击链接旁的「在侧栏预览」，或按住 Alt（macOS 为 Option）点击外链。环回 HTTP/HTTPS 链接也可直接进入侧栏。系统缺少内置网页能力时，网页可在系统浏览器打开，HTML 产物仍可查看源码。

侧栏使用独立的原生网页视图，网页直接处理鼠标、键盘和滚动，也没有桌面应用的 IPC 权限。HTTP/HTTPS 预览使用隔离代理，支持 Windows 和 macOS 14 及以上。HTML 产物可加载同目录的网页资源。本地开发服务要单独确认端口，并可在预览中撤销。

在支持内置浏览器的平台，新任务默认使用当前会话的原生网页标签。已有 Chromium 浏览器资料的任务会继续使用独立浏览器。可以在任务浏览器设置中选择浏览器来源，切换时需重新授权内网访问。Agent 操作内置网页期间，侧栏显示接手入口，暂停确认后恢复同一标签及页面状态。扩展所选标签保留在原浏览器中。

网页工具提供地址搜索、最近访问、页内查找、缩放、视口尺寸、按需截图、打开下载目录和清除账号浏览数据。清除前会提示其他会话的公网标签也将关闭，账号下的网页任务需先暂停。HTML 产物可查看源码，也可选择原文件中的文字或图片，调整文字、颜色、字号、粗体或图片路径，保存后可撤销和重做。脚本动态生成或无法定位到源码的元素，可以将选择带到聊天中，请 Agent 修改产物源码。

macOS 侧栏中的 Agent 可以观察、输入和点击嵌套及跨域框架。操作前会核对原文档、可见区域和逐层点击位置。框架移动、被遮挡或经过坐标变换时，Agent 会要求重新观察或由用户接手。

网页打开的登录弹窗在同一侧栏中成为原生标签，保留与来源页的通信关系和对应的浏览数据。弹窗完成并自行关闭后，侧栏回到来源标签。

## Browser Use 网络范围

受控浏览器的顶层导航、子资源及 WebSocket 经任务本地代理。默认只访问公网 HTTP/HTTPS，拒绝环回、私网、链路本地和保留地址，并校验 DNS 解析后的实际目标。用户可以为当前任务显式开启内网访问。侧栏预览的本地端口授权作用于本会话的预览标签页，撤销时断开旧连接并关闭对应标签页。文件上传限于当前授权工作区的普通文件，披露前还需单独确认。

macOS 和 Windows 在仅允许访问公网时，如果系统 DNS 查询超时或长时间未响应，内置浏览器和受控 Chromium 会尝试当前网络接口配置的 DNS。连接只使用通过公网地址校验的解析结果。

实现见 [`automation/mod.rs`](../src-tauri/src/automation/mod.rs)、[`network_proxy.rs`](../src-tauri/src/automation/network_proxy.rs)、[`browser.rs`](../src-tauri/src/automation/browser.rs) 和 [`computer.rs`](../src-tauri/src/automation/computer.rs)。
