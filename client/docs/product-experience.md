# 产品体验约定

EchoAgent 围绕真实工作目录组织任务。首页提供任务输入，目录、模型与权限就近配置；会话承载执行、确认、变更和成果。本文记录共享交互约定，专题功能以各自文档和当前实现为准。

## 任务、目录与接续

- 历史任务使用该会话实际绑定的工作目录。首页为下一任务选择目录，不改变正在查看的历史任务；目录选择取消不改变现有值，失败保留有效目录并提供重试。
- 创建或发送失败时保留输入、附件与草稿；等待确认、运行中、取消、失败和成功分别呈现。本轮模型输出结束不直接代表用户目标完成。
- 停止操作等待原生取消确认；排队与立即发送按实际消息身份处理，旧回合回放不能消耗新消息的待发送状态。
- 接续任务保留来源历史和未完成上下文；新任务标题来自本任务的输入，原会话保持不变。重复导航或被新导航取代的请求不能清除已经成功加载的历史。
- 重启恢复保留用户请求和已有成果，不自动重发结果未知的请求或工具操作。进程、窗口及草稿恢复见 [客户端恢复](desktop-recovery.md)。

## 找回任务

搜索入口支持会话和专家团。结果展示标题、可辨认的工作目录及匹配片段；同名任务仍需能够区分。

- 最近记录按更新时间排序并分批展示，明确剩余数量；改变查询后重置批次。
- 方向键移动、Enter 打开、Escape 关闭；中文输入法组合状态下的 Enter 不触发打开。全文结果迟到或去重替换条目时，以稳定任务身份保留键盘焦点。
- 搜索失败与打开失败独立保存，各自重试原操作；防抖搜索不能清除当前打开错误。
- 成功打开后关闭搜索。加载失败保留结果和重试入口；用户取消未保存内容保护时保留原页面，不显示伪造的读取失败。
- 改变查询、关闭重开或离开页面后，旧请求的迟到响应不能恢复过期提示，也不能抢走新输入的焦点。

## 知识来源与记忆

- 资料来源优先显示可读名称，保留稳定 ID 和原始路径用于实际操作。引用需能对应到当前回复的来源、路径、片段或行号；历史回放与本轮新执行分别处理。
- 添加、移除和打开失败时保留原数据并就地重试。原生选择器防止重复打开，取消选择不增删来源。
- 索引刷新独立于查看资料和来源维护；耗时重建期间仍可打开文件、添加或移除来源。降级为关键词搜索时说明当前可用能力。
- 来源变更持久化成功后才更新列表。撤销来源后，后续批次、重排和结果返回均排除它；已经发出的请求无法承诺撤回。
- 修改、忘记和删除记忆不能影响其他来源。自动标题、有效事实、旧数据兼容和提取检查点见 [记忆处理](memory-recovery.md)。

## 输入、布局与反馈

- 单一输入区域负责草稿、附件、`@` 和 `/`。空白区域可帮助聚焦，同时保留交互控件、文本选区与输入法行为。
- 复合输入框、分隔条与普通控件各有清楚的焦点提示，避免重复描边；长输入、大字号、侧栏缩放后操作仍可见、可点击。
- 主操作、已选状态、成功、待确认与错误采用独立语义角色，规则见 [主题设计](theme-design.md)。资源页面复用 [资源管理](resource-management-design.md) 的组件与布局。
- 桌面通知的成功提示只表示已向操作系统提交；任务执行结果和通知投递结果分别记录。关闭提醒后重启保持关闭，投递失败可查看原因，不自动重跑任务。
- 当前桌面窗口默认 1280×800、最小 1024×680。回归至少覆盖浅深主题、默认与大字号、最小与常用窗口，以及长标题、长错误、加载、空数据和失败重试。

## 回归入口

| 范围 | 入口 |
| --- | --- |
| 搜索、同名任务、资料管理及异步错误 | `pnpm test:ui:product-experience` |
| 工作目录与历史任务 | `pnpm test:ui:session-workspace` |
| 接续、回放与导航 | `pnpm test:ui:conversation-continuation` |
| 队列、停止与立即发送 | `pnpm test:ui:queue` |
| 后台任务、来源与执行结果 | `pnpm test:ui:background-execution`、`pnpm test:ui:execution-outcome` |
| 输入、焦点及桌面提醒 | `node scripts/validate-composer-feedback-ui.mjs` |
| 组件和跨请求时序 | `pnpm test` |

这些浏览器入口使用生产组件和受控 IPC；系统文件选择、实际模型、操作系统通知与重启需按 [开发与验收](testing.md) 分别执行原生流程。界面回归不能证明真实服务成功，也不能代替用户任务测试；评估易用性时另记录完成时间、误操作与求助位置。
