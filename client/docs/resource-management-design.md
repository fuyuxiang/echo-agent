# 资源管理页面

资源管理使用同一套密度、文字与交互规则，新增页面复用现有组件。

## 已有资源

专家、项目、专家团、技能、连接器、插件和定时任务使用 `ResourceList` 与 `ResourceRow`：

- 一个列表外框，条目之间用分割线区分，默认无阴影。
- 图标或头像、名称、说明、辅助信息、右侧操作采用固定的信息顺序。
- 对话、运行、编辑、启停等常用操作始终可见；删除继续通过确认流程执行。
- 定时任务状态显示在名称旁，进入批量管理后继续保留，便于确认删除对象。
- 插件说明默认预览两行，仅在实际超出时提供“展开说明”；完整内容可就地展开、收起，支持键盘操作和窗口、字号变化。
- 列表只负责展示，各功能继续管理自己的请求、权限、忙碌状态和错误处理。
- 连接器可展开配置、诊断与工具，不给条目增加独立的滚动区域。
- 定时任务保留计划、下次运行、最近结果和异常处理入口；完整要求、会话策略与历史记录在详情中查看。
- 按列表实际可用宽度换行操作区，兼容侧栏调整和字号设置。长标题可以换行，关键状态不截断。

## 创建入口

专家、项目、定时任务模板复用 `TemplateCard`，排列在 `template-grid` 中：

- 使用功能图标、名称、最多两行说明，以及可选的分类和标签。
- 整张卡片是原生按钮，只准备创建草稿，不自动保存或运行。
- 专家团模板因同时提供复用与删除，使用相同的 `resource-template` 外观和独立操作按钮，避免嵌套按钮。
- 根据内容自然增高，不设置固定高度或独立滚动条。

## 尺寸与主题

统一变量定义于 `src/styles/tokens.css`，组件样式位于 `src/styles/resource-collections.css`。

默认图标容器 36px、内边距 16px、间隔 12px、圆角 12px；普通列表行最小高度 88px，模板和定时任务最小高度 112px。标题、说明、辅助信息分别使用 `.875rem`、`.8125rem`、`.75rem`。这些是最小高度和相对字号，放大文字或内容换行时允许自然增高。

颜色使用已有语义变量，以支持亮暗主题。键盘焦点可见，减少动态效果设置下关闭过渡。

## 验证

- `pnpm test:ui:resource-collections`：生产 React/CSS 的资源布局、模板一致性、搜索、错误重试、连接器配置、技能和插件启停；包含说明展开与收起、键盘焦点、窄窗口及大字号。
- `pnpm test:ui:scheduled-tasks`：任务列表、批量管理状态、筛选、模板草稿、编辑、运行、结果与异常恢复。
- `pnpm test:ui:management-pages`：管理页面与窗口导航。
- `node scripts/validate-group-lifecycle-ui.mjs`：专家团创建、模板复用、归档、恢复及删除。

浏览器验收替换原生 IPC，使用隔离数据，不改动用户配置或派发真实模型任务。原生服务契约由现有业务测试继续覆盖。
