# 内置办公文档能力

EchoAgent 可在任务中读取工作区内的常见办公文档，并在本机生成 Word、PDF、Excel 和 PowerPoint 文件。生成器随桌面安装包分发，不需要用户安装 Office、LibreOffice、Python 或单独的文档转换服务；模型调用仍使用当前任务配置的模型服务。

## 怎么使用

会话内的文档预览兼容包含空目录、空文件和流式压缩条目的 OOXML 文件。表格按单元格坐标保留空列与行间隔，并按工作表数字顺序展示；这不是 Excel 的计算或排版引擎。预览最多读取 8 MiB ZIP、512 个条目，单条目解压最多 4 MiB、合计最多 16 MiB；工作簿合计最多展开 10,000 行（包括空行）、100,000 个单元格，每行最多 16,384 列。损坏、格式不支持或超过限制时提示使用系统应用打开原件，原始文件不变。

本地文件夹知识源的 XLSX 文本索引使用独立预算：按工作表数字顺序提取实际单元格内容，不展开空行和空列，最多索引每文件前 524,288 个字符。高行号本身不会导致正文无法搜索；ZIP 输入和解压保护仍然生效。达到字符上限后的内容不参与该本地索引，预览无法展开时仍可打开原件。

1. 在 Agent 任务中指定已授权的工作目录，提出“做一份 Word 报告”“将表格整理成 Excel”等要求。Agent 可调用内置 `office_create`，默认保存到该工作区的 `EchoAgent成果/`。指定文件名和输出子目录时会按要求保存；已有文件受到保护。
2. 对一条回复使用「导出」，选择 Word、PDF、Excel 或 PPT，通过系统保存对话框指定位置。
3. 会议纪要另有 Word、PDF 和 Markdown 导出入口。

| 输出 | 内容组织方式 |
| --- | --- |
| Word / PDF | 从 Markdown 的标题、段落、列表、代码和表格生成内容 |
| Excel | 从 Markdown 表格生成工作表；长编号、前导零和公式样本按文本处理 |
| PPT | 按标题划分幻灯片 |

内容型文档适合此入口。原件的精确版式修改、扫描件 OCR、PDF 页面重排等应使用对应的专门工具或流程。完整嵌入中文字体的 PDF 文件可能较大。

## 在成果中预览与修订 Word

打开任务「成果」中的 Word 文件，即可按段落、标题和真实表格查看内容。新生成的 Word 同时保存一份可编辑源稿：点「编辑」会展开文档工作区，可以直接修改文字、标题、基础格式和表格，支持增删行列、撤销和重做。修改立即呈现，停止输入后自动保存编辑稿，再同步到原 Word；顶部会分别显示保存与同步状态。关闭面板或切换文件不会取消待保存的修改。

选中一段文字后点「让 Agent 修改」，也可以不选择内容修改全文。输入框会显示当前文档，用户在现有对话中填写要求并发送，Agent 先通过 `office_document_read` 读取最新源稿，再以读取到的版本号调用 `office_document_update`。手动编辑和 Agent 共用同一源稿；冲突时保留本地编辑，用户可以读取最新稿或将自己的修改另存为副本。排队的修改指令也会保留所属文档。

「版本历史」保留最近 20 个旧版本，并受总大小限制；恢复会创建新版本。「导出」按当前源稿另存 Word 或内容型 PDF。编辑稿在本机持久保存，未完成的输入还有本机恢复副本。原 Word 被其他应用改动时会停止覆盖，提示另存副本；删除任务会清理该任务的编辑源稿和恢复数据，工作区成果文件仍按原有任务删除规则保留。

恢复历史、读取最新稿和创建副本期间暂时锁定编辑；迟到的新输入会保留并提示核对。Word 同步错误独立显示，不会被后台刷新清除；暂时失败最多自动尝试三次，之后可手动重试。重新打开文档会继续同步已经保存的待同步版本，外部修改仍受到保护。

历史 Word、外部 Word 和 Markdown 可以先预览，再显式「创建可编辑副本」，保留原件。当前编辑范围为文字、三级标题、列表、引用、代码、链接、基础文字格式和简单表格，最多 1,000 行、32 列，不支持跨行合并。含图片、修订、页眉页脚等复杂内容的外部 Word 提示使用系统应用查看，避免转换时遗漏内容。这里提供内容与基础格式的即时呈现，Word 精确分页和复杂版式以实际导出文件为准。

Markdown 阅读继续保留原有图片预览、公式和 Mermaid 图表。含图片、公式、图表、HTML、任务复选框等无法完整转换的内容时，会说明原因并禁用创建可编辑副本，避免静默遗漏。普通导出中的相对路径和页内链接保留为可读文字，不创建本地文件超链接，也不会阻断其他格式导出。可编辑文档导出的 PDF 保留横向合并单元格的列位置和单元格内的段落换行。

需要可计算公式、原生图表或精确页数时，Agent 在同一个 `office_create` 中使用结构化内容，无需额外设置：

- Excel 的 `workbook.sheets` 定义工作表、行、格式和图表。普通字符串始终保留为文本，公式使用显式的 `formula` 单元格。支持算术、比较、SUM、AVERAGE、MIN、MAX、COUNT、ROUND、IF、IFERROR 和本工作簿内跨表引用，生成时检查公式并写入计算缓存，打开时允许重新计算。ROUND 按十进制舍入，正负数的中点均向远离零的方向处理，依赖公式与图表使用同一份结果。柱状图和折线图引用真实单元格范围，默认排在数据下方；列宽自动估算，也可显式指定。外部工作簿、宏和其他函数不会静默执行，超出范围或存在无法可靠计算的类型组合时工具返回具体错误。
- PPT 的 `slides` 定义实际页面，封面也计入列表；支持文字、原生表格和柱状/折线图。内容过多时返回精简或拆页提示，不额外增加页面。
- `outputPath` 接受工作区内相对路径或绝对路径，自动创建缺失的父目录，拒绝向上遍历、目录符号链接和工作区外路径。路径声明不授予新权限。
- `requestId` 标识同一次生成。相同内容重试时核对已保存文件的摘要并返回原回执；更换内容、删除或修改原文件时明确提示。没有标识也没有指定路径的独立调用继续生成不同文件。

未完成任务的明确交付路径和 JSON 输出要求在暂停、继续及重启后保留。可以明确指定新的交付路径替换原清单，用“另外交付”追加成果，或用“不再生成文件”“改用自然语言”取消对应要求；完成后开始的新任务不沿用旧要求。交付检查只将交付动作直接指定的文件列为目标，参考文件、输入来源和通配符不作为待生成成果。

## 文件与权限边界

`office_create` 的文件及生成临时文件保存在当前任务工作区的输出目录，不能覆盖已有文件。桌面回复导出使用用户选择的保存路径。输出在写盘前检查格式、非空与不超过 50 MiB，并计算 SHA-256；输入内容上限为 2 MiB。文档内容在本机由安装包内的 Node.js、文档 worker 和字体处理。

实现入口见 [`office_mcp.rs`](../src-tauri/src/office_mcp.rs)、[`document_export.rs`](../src-tauri/src/document_export.rs) 和 [`office-worker.mjs`](../scripts/office-worker.mjs)。开发者可运行 `pnpm office:test` 验证四种生成格式。

文档工作区入口见 [`DocumentWorkbench.tsx`](../src/components/DocumentWorkbench.tsx) 和 [`document_workspace.rs`](../src-tauri/src/document_workspace.rs)。运行 `pnpm test:document-workspace` 检查编辑模型、保存恢复、原生持久化和实际 Word/PDF 输出；运行 `pnpm test:ui:document-workspace` 检查浏览器中的表格编辑、自动同步、Agent 更新、版本恢复和冲突另存流程。
