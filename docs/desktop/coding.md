# 代码任务与文件变更

EchoAgent 的会话可以在已授权的工作目录中读取和修改文件。代码任务沿用普通会话的模型选择、工具活动和权限确认。

## 开始代码任务

1. 在首页选择代码所在的目录、模型和权限模式。
2. 说明要修改的内容、需要保留的行为和验证方式。
3. 查看工具活动。收到权限请求时，核对操作对象和目录。

例如，可以请 Agent 修复一个已知问题、补充相关测试，并说明改动的文件和测试结果。项目需要的解释器、编译器和依赖应在工作目录所在的系统中准备好。

## 检查修改和结果

打开会话中的「文件变更」核对差异，也可以从工作区文件树查看当前文件。检查实际测试输出和失败提示。需要调整时，在同一会话里补充要求。
