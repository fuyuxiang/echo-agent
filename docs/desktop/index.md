# Desktop 使用指南

**适用范围：EchoAgent Desktop（Client）。** 本节面向桌面安装包用户。独立 Python Runtime 的命令、YAML 配置和 Dashboard 操作见 [Runtime 使用指南](../guides/index.md)。

桌面端围绕“在实际工作目录中完成任务”组织功能。一个任务可以读取资料、制定计划、使用工具并生成文件；用户在执行过程中查看状态、处理权限请求，在结束后检查变更与交付物。

| 阶段 | 阅读内容 | 完成后应能做到 |
| --- | --- | --- |
| 安装 | [安装与环境要求](installation.md) | 打开应用，确认功能可用 |
| 入门 | [快速开始](quickstart.md) | 在指定目录生成并核对一个文件 |
| 日常使用 | [任务与权限](tasks-permissions.md) | 选择权限、补充要求并检查结果 |
| 专项任务 | [代码](coding.md) · [自动化](automation.md) · [知识与记忆](knowledge-memory.md) | 选择适合任务的工具和验证方法 |
| 配置与协作 | [模型与扩展](models-extensions.md) · [专家团与定时任务](collaboration-scheduling.md) | 接入模型、能力和持续工作流程 |
| 维护 | [数据与故障排查](operations.md) | 备份、恢复和定位问题 |

实现思路见[架构总览](../concepts/architecture.md)和[桌面端架构与数据流](../concepts/desktop-architecture.md)。
