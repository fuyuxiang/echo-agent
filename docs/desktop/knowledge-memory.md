# 文档、知识与记忆

**适用范围：桌面端。** 文档是交付物，知识源是任务可检索的资料，记忆是跨任务复用的偏好与事实。三者用途不同，应分别管理。

## 生成与导出文档

在任务中指定输出格式、内容和保存位置。例如：

> 读取当前目录中的会议记录，生成一份 Word 行动清单，包含负责人、事项、截止时间。缺失信息标为“待确认”，保存到当前工作区。

内置生成器支持 Word、PDF、Excel 和 PowerPoint，无需安装 Office、LibreOffice 或 Python。未指定位置时，任务生成文件默认保存在工作区的 `EchoAgent成果/`；已有文件受到保护。回复也可通过“导出”选择格式和保存位置。

| 输出 | 使用方式与范围 |
| --- | --- |
| Word / PDF | 根据标题、段落、列表和表格组织内容 |
| Excel | 从表格生成工作表；结构化生成支持限定公式、格式与原生图表 |
| PowerPoint | 按标题组织页面；结构化生成可指定页数、表格与图表 |

精确修改既有文档版式、OCR、PDF 重排需要专门流程。Excel 不提供完整的计算引擎；超出已支持函数、外部工作簿或宏的要求会返回限制。预览也不等同于原应用排版，应打开最终文件验收。

## 使用知识源

为任务选择资料或本地知识来源，再明确提出基于这些材料回答。索引将可提取文本分块，按查询找出相关片段供模型使用。没有被提取或超过索引预算的内容不会自动成为检索依据。

可以要求“每个结论注明来源，资料中没有的内容明确说明”。资料更新后检查索引是否已更新。个人与组织知识按所选来源使用；来源私聊只在明确勾选引用后共享到专家团。

## 管理长期记忆

打开“设置 → 记忆”，管理总开关、记忆内容和来源。任务后可自动提取有依据的个人偏好、工作背景、项目事实和近期事项；全局偏好可跨项目使用，项目事实按工作区隔离。

支持添加、更正、遗忘、查看来源，以及文本或 JSON 预览导入、复制导出。手动保存的记忆不会被自动整理覆盖。临时事项可标记完成或设置有效期。

更正和遗忘会排除旧事实及关联来源的后续使用；已停用内容可供检查，原聊天仍在历史中。关闭总开关会停止后续记忆使用与自动提取，已有内容仍可管理。

## 判断应该保存在哪里

| 内容 | 保存方式 |
| --- | --- |
| 可交付报告与表格 | 实际文件，并打开核对 |
| 项目规范、参考文档 | 知识源，保留来源与更新记录 |
| 稳定偏好、项目事实 | 记忆，注明适用范围 |
| 当前任务的中间过程 | 会话与执行记录 |

检索可能使用远端嵌入与重排服务。“资料在本机”不意味着检索文本不会发送到服务端，详见[数据边界](operations.md)。
