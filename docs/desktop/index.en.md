# Desktop guide

**Scope: EchoAgent Desktop (Client).** See [Runtime guides](../guides/index.md) for standalone Python commands, YAML configuration, and Dashboard operations.

Desktop organizes tasks around an actual working directory. A task can read material, make a plan, use tools, and produce files. You can inspect progress, respond to permission requests, and review changes and deliverables.

| Stage | Read | Expected outcome |
| --- | --- | --- |
| Install | [Installation](installation.md) | Launch and check capabilities |
| Start | [Quickstart](quickstart.md) | Generate and verify a file |
| Daily work | [Tasks and permissions](tasks-permissions.md) | Set permissions, refine requests, and verify results |
| Specialized work | [Coding](coding.md) · [Automation](automation.md) · [Knowledge and memory](knowledge-memory.md) | Choose tools and verification methods |
| Configuration | [Models and extensions](models-extensions.md) · [Groups and scheduling](collaboration-scheduling.md) | Configure models, capabilities, and ongoing work |
| Maintenance | [Data and troubleshooting](operations.md) | Back up, restore, and diagnose issues |

Read [Architecture](../concepts/architecture.md) and [Desktop architecture and data flow](../concepts/desktop-architecture.md) for the design.
