# TUI 命令参考

Echo Agent 的交互式终端 UI（TUI）支持斜杠命令，用于会话管理和服务端操作。

## 本地命令

本地命令在客户端执行，不需要服务端连接。

| 命令 | 说明 | 快捷键 |
|------|------|--------|
| `/help` | 显示所有可用命令帮助 | `F1` |
| `/clear` | 清空当前会话显示区域 | `Ctrl+L` |
| `/copy` | 复制最近一条 Agent 回复到剪贴板 | `Ctrl+Shift+C` |
| `/details` | 显示当前消息的详细元数据（token 用量、延迟等） | — |
| `/save` | 将当前会话导出为 Markdown 文件 | — |
| `/theme` | 切换 UI 主题（dark/light/auto） | — |
| `/reconnect` | 重新连接 WebSocket（断线后使用） | — |
| `/quit` | 退出 TUI 客户端 | `Ctrl+C` / `Ctrl+D` |

### /help

```
/help [command]
```

不带参数时显示所有命令列表。带参数时显示指定命令的详细帮助。

### /clear

```
/clear
```

清空 TUI 的消息显示区域。不会影响服务端会话历史。

### /copy

```
/copy [n]
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `n` | int | 1 | 复制最近第 n 条 Agent 回复 |

### /details

```
/details
```

显示最近一条消息的元数据：

- Token 用量（input / output）
- 模型名称与版本
- 响应延迟（ms）
- 工具调用记录

### /save

```
/save [path]
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `path` | string | `./session_<id>_<timestamp>.md` | 导出文件路径 |

导出格式为带时间戳的 Markdown，包含用户消息和 Agent 回复。

### /theme

```
/theme [name]
```

可选主题值：

| 值 | 说明 |
|----|------|
| `dark` | 深色主题 |
| `light` | 浅色主题 |
| `auto` | 跟随系统设置 |

不带参数时循环切换主题。

### /reconnect

```
/reconnect
```

手动触发 WebSocket 重连。TUI 内置自动重连机制（指数退避），通常无需手动调用。适用于网络切换后连接未自动恢复的情况。

### /quit

```
/quit
```

优雅退出 TUI 客户端。等价于 `Ctrl+C` 或 `Ctrl+D`。退出前会发送断开通知到服务端。

## 服务端命令

服务端命令通过 WebSocket 发送到 Echo Agent 后端执行。需要活跃的服务端连接。

| 命令 | 说明 | 权限要求 |
|------|------|----------|
| `/approve` | 批准待审工具调用 | 会话所有者 |
| `/deny` | 拒绝待审工具调用 | 会话所有者 |
| `/approvals` | 查看所有待审项 | 会话所有者 |
| `/clarify` | 向 Agent 发送澄清信息 | 会话所有者 |

### /approve

```
/approve [request_id]
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `request_id` | string | 最近一条 | 批准指定的工具调用请求 |

!!! tip "批量审批"
    使用 `/approve all` 可批准当前所有待审项。

### /deny

```
/deny [request_id] [reason]
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `request_id` | string | 最近一条 | 拒绝指定的工具调用请求 |
| `reason` | string | — | 拒绝原因（可选，会记录到日志） |

### /approvals

```
/approvals
```

显示当前会话中所有等待审批的工具调用，包含：

- 请求 ID
- 工具名称
- 参数摘要
- 等待时间

### /clarify

```
/clarify <message>
```

在 Agent 执行过程中插入澄清信息。Agent 会将此消息作为额外上下文处理，不中断当前工作流。

!!! warning "注意"
    `/clarify` 不会中断正在执行的工具调用。如需立即停止，使用 `/deny` 拒绝待审操作。

## 命令执行流程

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  用户输入   │────▶│  命令解析器  │────▶│  本地执行   │
│  /command   │     │              │     │  或 WS 发送 │
└─────────────┘     └──────────────┘     └─────────────┘
                           │                     │
                           ▼                     ▼
                    ┌──────────────┐     ┌─────────────┐
                    │ 未知命令回退 │     │  服务端处理 │
                    │ 作为消息发送 │     │  返回结果   │
                    └──────────────┘     └─────────────┘
```

!!! question "需维护者确认"
    未知斜杠命令的默认行为：当前作为普通消息发送，是否应改为报错提示？
