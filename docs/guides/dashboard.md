# Dashboard 使用

Echo Agent Dashboard 是一个 Web 管理界面，用于监控系统状态、管理会话与资源、查看日志和分析数据。

!!! question "需维护者确认"
    Dashboard 默认监听端口及认证配置方式（如 API Key、OAuth）需由维护者根据部署环境确定。

## 架构概览

Dashboard 采用前后端分离架构：

- **前端**：单页应用（SPA），提供实时状态面板与操作界面
- **后端 API**：位于 `gateway/api/` 目录，负责数据聚合与权限校验
- **WebSocket**：用于日志流、会话状态等实时推送

## 访问方式

启动 Echo Agent 后，在浏览器中访问：

```
http://<host>:<port>/dashboard
```

!!! question "需维护者确认"
    默认端口号需确认，通常为 `8080` 或在 Config 页面中配置。

## 页面导航

Dashboard 左侧为主导航栏，包含以下页面：

| 页面 | 功能 |
|------|------|
| Overview | 系统总览与健康状态 |
| Sessions | 会话管理 |
| Memory | 记忆存储浏览 |
| Skills | 技能管理 |
| Knowledge | 知识库管理 |
| Cron | 定时任务 |
| Kanban | 任务看板 |
| Logs | 系统日志 |
| Analytics | 使用分析 |
| Config | 运行时配置 |
| Channels | 通道配置 |

---

## 各页面详细说明

### Overview（系统总览）

显示系统整体运行状态的仪表盘。

**关键功能：**

- 当前活跃会话数量
- 系统资源占用（CPU、内存）
- 各通道连接状态
- 最近事件时间线

<!-- 截图占位：Overview 页面全貌，展示状态卡片与资源图表 -->

### Sessions（会话管理）

查看和管理所有活跃与历史会话。

**关键功能：**

- 查看活跃会话列表及详情
- 浏览历史会话记录
- 手动终止异常会话
- 按通道、时间筛选会话

<!-- 截图占位：Sessions 列表页，显示会话状态、来源通道、持续时间 -->

### Memory（记忆浏览）

浏览和搜索各层级记忆条目。

**关键功能：**

- 按四个层级筛选浏览：`working`、`episodic`、`semantic`、`archival`
- 检索记忆内容
- 查看记忆元数据
- 删除记忆条目（页面不提供手动创建入口）

该页面是跨主体视图：列表与搜索均需要 admin 令牌，普通 API 令牌只能读取自身作用域内的记忆。

<!-- 截图占位：Memory 搜索界面，展示记忆条目卡片与层级筛选 -->

### Skills（技能管理）

管理已安装的技能及其配置。

**关键功能：**

- 查看已安装技能列表
- 启用/禁用单个技能
- 查看技能触发条件与描述
- 技能执行日志

<!-- 截图占位：Skills 页面，展示技能卡片网格与启用状态开关 -->

### Knowledge（知识库管理）

管理文档和知识库内容。

**关键功能：**

- 上传文档并触发索引重建
- 浏览已索引文档（显示路径、大小、修改时间）
- 查看索引状态：文档数、分块数、是否陈旧、上次重建时间

上传、删除与重建索引在服务端均受 admin 守卫保护。页面不提供文档分类或标签功能。

<!-- 截图占位：Knowledge 页面，展示文档列表与索引状态指示器 -->

### Cron（定时任务）

配置和监控定时执行的任务。

**关键功能：**

- 创建/编辑/删除定时任务
- 查看 Cron 表达式与下次执行时间
- 手动触发任务执行
- 查看任务执行历史与结果

<!-- 截图占位：Cron 页面，展示任务表格与执行时间线 -->

### Kanban（任务看板）

以看板形式可视化管理任务。

**关键功能：**

- 拖拽任务卡片变更状态
- 切换是否显示归档列（`cancelled`、`suspended`）

拖拽依赖写权限：只读令牌下看板以只读方式呈现，而不是提供每次拖拽都返回 403 的控件。

<!-- 截图占位：Kanban 页面，展示多列看板与任务卡片 -->

### Logs（系统日志）

实时查看系统运行日志。

**关键功能：**

- 实时日志流（WebSocket 推送）
- 按级别筛选（DEBUG / INFO / WARN / ERROR）
- 按模块与时间范围过滤
- 日志导出

<!-- 截图占位：Logs 页面，展示日志流与级别过滤控件 -->

### Analytics（使用分析）

统计使用数据与模型调用成本。

**关键功能：**

- 模型调用次数与 Token 消耗趋势
- 各模型成本明细
- 按通道/技能维度的使用分布
- 自定义时间范围报表

<!-- 截图占位：Analytics 页面，展示折线图、饼图与成本汇总表 -->

### Config（运行时配置）

管理系统运行时参数，无需重启服务。

**关键功能：**

- 编辑模型提供者配置（API Key、端点）
- 调整记忆策略参数
- 修改日志级别
- 管理环境变量覆盖
- 配置变更历史与回滚

!!! warning "注意"
    Config 页面的修改会即时生效，请谨慎操作。建议在非高峰时段进行配置变更。

<!-- 截图占位：Config 页面，展示配置表单与变更历史面板 -->

### Channels（通道配置）

配置消息通道的连接参数。

**关键功能：**

- 添加/编辑/删除通道
- 配置通道认证信息
- 查看通道连接状态与健康检查
- 通道消息吞吐量监控

<!-- 截图占位：Channels 页面，展示通道列表与连接状态指示灯 -->

## 访问控制

!!! warning "安全提示"
    Dashboard 默认不应暴露在公网。建议通过反向代理配合认证中间件保护访问，或限制监听地址为 `127.0.0.1`。

!!! question "需维护者确认"
    具体认证方式（Basic Auth、Token、OAuth2）需根据部署方案确定。

## 监控与告警

通过 Overview 和 Analytics 页面，可实现：

- 系统健康状态实时监控
- 资源使用率告警阈值配置
- 模型成本预算监控
- 异常会话自动检测
